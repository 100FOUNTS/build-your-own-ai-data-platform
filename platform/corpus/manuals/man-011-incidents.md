# Responding to a pump failure

## First minutes
1. Make people safe and notify the shift supervisor.
2. If there is a risk, stop the pump and apply LOTO.
3. Put the standby pump into service to restore the service.
4. Immediately create a corrective work order with the observed failure mode.

## Recording the work order
The corrective work order must include the asset, the opening date and time, the failure mode (bearing, seal, cavitation or other), the downtime hours and the estimated cost. This data is the label the predictive models are trained and evaluated with, so it must be accurate.

## Follow-up report
Within the next 24 hours the reliability engineer writes a short report with the sequence of events. Within 5 working days the root cause analysis is completed using the five whys technique.

## Indicators
MTBF (mean time between failures) and MTTR (mean time to repair) are computed per failure mode. If the MTTR of a mode exceeds 48 hours twice in a row, review the spare parts inventory.

## Communication
Report the closing of the incident to operations and record the lessons learned in the knowledge repository.
